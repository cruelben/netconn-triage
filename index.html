Which programs is your PC talking to?

Load the report created by the checker script. This page sorts the connections by risk, shows the file behind each one and prepares whitelist entries.

Drop outbound-connection-report.json here or press Enter to choose the file

Paste the JSON instead
  1. Run run.bat as administrator.
  2. The checker saves outbound-connection-report.json next to the script.
  3. Drop that file here, or choose it. After the next scan, Refresh report reads the same file again without asking.

The report contains process names, file paths, hashes and remote addresses from your PC. It stays in this browser tab: the page can only contact the address it was loaded from, never sends the report anywhere, and stores nothing except your theme choice. The only outgoing link is the optional VirusTotal lookup, which opens in a new tab when you click it.

This is a snapshot of established TCP connections. UDP traffic and very short connections are not included, and a Normal status does not guarantee that a program is safe.

Build whitelist lines

Pick only programs you have verified. Paste the lines into whitelist.txt, next to controllo-connessioni.ps1. Each line trusts one exact file: the path and the SHA256 must both match.
